# Changelog — v1.0.0 (Flipper)

## 🎉 Initial Release

### Added
- Core Flipper Zero device management (qFlipper-style interface)
- FAP builder and compiler with project scaffolding
- Firmware builder supporting Unleashed, Xtreme, Momentum, Official bases
- Arduino and ESP32 support with Arduino CLI integration
- GitHub repository search, code search, and direct downloads
- Embedded terminal with FBT command integration
- File handlers for FAP, DFU, tar.gz, zip archives
- Plugin system for custom extensions
- Cross-platform support: macOS 10.15+, Linux (Ubuntu 20.04+), Windows 10+

### Infrastructure
- Initial project scaffold and build system
- Python requirements and Node.js package configuration
- Setup script for one-command installation
